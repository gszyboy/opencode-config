# 参考图编辑 / Reference-based Edit

> 改图、改风格、保留主体的场景。显式说"Keep X, Y, Z exactly the same"。

## E1 · 换背景
**size**: `1k`  ·  **quality**: `high`

```
Change only the background to a clean white seamless studio backdrop
with soft top-down lighting. Keep the product shape, label layout,
cap color, surface reflections, and camera angle exactly the same.
Do not move, resize, or re-style the product.
```

## E2 · 换季节/天气
**size**: `landscape`  ·  **quality**: `high`

```
Edit image 1: change only the season from summer to deep winter with
heavy snowfall. Same location, same camera angle, same subjects in
the same positions. Add snow on the ground, on the rooftops, and on
the bare trees. Add light snowflakes in the air. Keep the building
shapes, the people (in winter coats), and the overall composition
exactly the same.
```

## E3 · 服装换色
**size**: `portrait`  ·  **quality**: `high`

```
Edit image 1: change only the color of the jacket to pastel mint
green (#A8E6CF). Keep everything else — the person's pose, facial
expression, hairstyle, background, lighting direction, camera
angle, and image grain — exactly the same. No other modifications.
```

## E4 · 时间/光线变化
**size**: `landscape`  ·  **quality**: `high`

```
Re-light image 1 as if it were captured at blue hour instead of
midday. Keep the buildings, the street, the camera position, the
people, and the framing exactly the same. Add deep blue ambient
sky, warm yellow window lights turning on, sodium street lamps
glowing, slight headlight bloom from distant cars. No new objects
introduced.
```
