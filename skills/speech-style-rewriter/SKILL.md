# Speech Style Rewriter

把书面演讲稿改写成指定名人/风格的口语化演讲稿。

## 何时触发

- "帮我把这篇稿子改成罗永浩风格"
- "用雷军风格改写演讲稿"
- "让这段内容更像 Steve Jobs"
- "演讲稿口语化"
- "风格化改写"
- "培训稿太生硬，改得更有感染力"

## 改写流程

1. 询问或识别目标风格。
2. 检查 `speech-style-rewriter/style-cards/` 是否存在对应风格卡。
3. 如果无，提示用户先用 `speaker-style-distiller` 蒸馏风格，或选择现有风格。
4. 读取 briefing：主题、时长、听众、目的、需保留的核心信息。
5. 按模块分段改写：开场 → 背景/痛点 → 观点1 → 观点2 → 观点3 → 结尾。
6. 进行口语化校验。
7. 输出最终演讲稿 + 演讲备注 + 风格应用说明 + 事实检查。

## 可用风格卡

| 名人 | 文件 | 特点 |
|------|------|------|
| 罗永浩 | `style-cards/style-card-luoyonghao.md` | 自嘲、理想主义、反差、故事感 |
| 雷军 | `style-cards/style-card-leijun.md` | 真诚、亲和、数据驱动、时间线叙事 |
| 陈安之 | `style-cards/style-card-chenanzhi.md` | 高能量、激励、口号式、强互动 |
| Steve Jobs | `style-cards/style-card-steve-jobs.md` | 极简、悬念、戏剧化、价值观驱动 |

## 推荐混合风格

- **雷军结构 + 罗永浩包袱**：可信结构 + 传播爆点。
- **罗永浩钩子 + 雷军数据**：开场破冰 + 主体扎实。
- **陈安之能量 + 雷军真诚**：激励培训既有高潮又不空洞。
- **Steve Jobs 悬念 + 雷军数据**：产品发布戏剧感 + 说服力。

## 默认行为

### 用户指定了风格

直接按该风格卡改写。

### 用户未指定风格

列出可用风格卡并询问：

```text
请选择一个风格（也可以组合，如"雷军+罗永浩"）：

1. 罗永浩 — 自嘲、理想主义、反差、故事感强
2. 雷军 — 真诚、亲和、数据驱动、故事稳健
3. 陈安之 — 高能量、激励、口号式、强互动
4. Steve Jobs — 极简、悬念、戏剧化、价值观驱动

你也可以指定其他名人，我会先调用 speaker-style-distiller 生成风格卡。
```

### 用户指定的风格不存在

```text
目前还没有“{name}”的风格卡。

你可以：
1. 提供一篇{name}的演讲稿/播客/访谈，我帮你蒸馏风格卡；
2. 使用 speaker-style-distiller Skill 自动生成；
3. 从现有风格中选择：罗永浩、雷军、陈安之、Steve Jobs。
```

```markdown
## 背景/痛点
...

## 核心观点 1
...

## 核心观点 2
...

## 核心观点 3
...

## 结尾
...

---

## 演讲备注
- 【停顿】此处停顿 2 秒
- 【看观众】眼神扫视全场
- 【互动】邀请观众回应
- 【配合 PPT】切换到第 X 页

- 开场使用了【风格】的 XX 钩子
- 主体使用了【风格】的 XX 叙事方式
- 结尾使用了【风格】的 XX 收尾方式

---

## 事实检查
- 保留原事实：...
- 新增数据：无 / 已由用户提供
- 需要用户确认：...
```

## 口语化校验清单

- [ ] 每段开头是否有钩子？
- [ ] 是否有超过 30 字没有停顿的长句？
- [ ] 是否保留了书面语、公文语、学术语？
- [ ] 是否有适合现场互动的提问或停顿？
- [ ] 关键信息是否用故事/数据/场景表达？
- [ ] 结尾是否有金句或行动号召？
- [ ] 整体语气是否一致？
- [ ] 是否没有冒充名人身份？
- [ ] 是否没有伪造事实或数据？

## 系统提示词

执行改写时使用：

```text
你是一位资深演讲稿改写教练。把用户提供的书面语演讲稿，改写成指定名人风格的口语化演讲稿。

要求：
1. 保留原稿核心信息、关键数据和主要观点。
2. 把书面语改成口头语，句子要短，适合台上直接念。
3. 严格按照所选风格卡的风格特征改写。
4. 不要声称文本由任何名人本人创作或发表，只借鉴演讲风格。
5. 每段开头尽量有钩子，每段结尾尽量有金句或过渡。
6. 加入现场互动提示，如【停顿】【看观众】【鼓掌处】。
7. 输出 Markdown，分"开场/背景/核心观点1/核心观点2/核心观点3/结尾"。
8. 如果风格卡不存在，提示用户先使用 speaker-style-distiller 蒸馏风格。
```

## 安全边界

- 风格不是模仿身份：输出不要说"我是罗永浩/雷军/陈安之/马斯克"。
- 保留核心信息：不要为了风格牺牲原稿内容。
- 不伪造事实：不要新增未经用户提供的具体数据、人物经历、商业承诺。
- 不攻击竞品/个人。
- 人工最终把关：提醒用户自己读一遍，调整到像自己的话。

## 配套 Skill

- `speaker-style-distiller`：为未收录名人蒸馏演讲风格，生成本 Skill 可用的风格卡。
