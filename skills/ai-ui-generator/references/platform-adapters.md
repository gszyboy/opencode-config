# 平台适配规则

## H5（移动网页）

适配关键词：
```text
mobile H5
mobile-first
scrollable layout
bottom tabbar
marketing-oriented
```

推荐组件：
- 长滚动页面
- 卡片流
- Banner
- Feed

适配要点：
- 必须考虑移动端触摸操作
- 底部固定导航或 TabBar
- 长滚动页面设计
- 营销导向的布局

---

## 微信小程序

适配关键词：
```text
wechat mini program
wechat ecosystem
safe-area layout
mini-program tabbar
```

推荐组件：
- 宫格
- 强入口
- 运营位
- 微信生态组件

适配要点：
- 必须适配微信安全区
- 使用微信小程序 TabBar 规范
- 宫格布局常用
- 强入口设计

---

## App（原生应用）

适配关键词：
```text
native mobile app
immersive experience
gesture-friendly
native iOS style
```

推荐组件：
- 原生导航
- 沉浸式布局
- 原生 tabbar

适配要点：
- 原生导航栏
- 沉浸式体验设计
- 手势友好
- 原生 iOS/Android 风格

---

## PC Web（桌面端）

适配关键词：
```text
desktop web
responsive layout
wide screen
mouse-friendly
```

推荐组件：
- 导航栏
- 侧边栏
- 宽屏布局
- 表格

适配要点：
- 响应式设计
- 宽屏适配
- 鼠标操作优化
- 多列布局

---

## Admin（管理后台）

适配关键词：
```text
desktop dashboard
sidebar navigation
analytics layout
high information density
```

推荐组件：
- Table
- Charts
- Sidebar
- KPI Cards

适配要点：
- 侧边栏导航
- 数据分析布局
- 高密度信息展示
- 表格和图表为主
