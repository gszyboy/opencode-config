# 最终输出模板

## 模板结构

```text
A highly realistic [PLATFORM] UI screenshot.

App type:
[PRODUCT]

Page:
[PAGE]

Layout:
[LAYOUT]

Design system:
[DESIGN_SYSTEM]

Components:
[COMPONENTS]

Style:
[STYLE]

Requirements:
[IMPLEMENTATION]

Negative constraints:
[NEGATIVE]

Must look like a real internet product.
Ultra detailed.
```

## 字段填充说明

### [PLATFORM]

根据平台选择：
- mobile H5
- wechat mini program
- native mobile app
- desktop web
- desktop dashboard

### [PRODUCT]

描述产品类型，例如：
- AI travel assistant platform
- E-commerce marketplace
- SaaS analytics dashboard
- Social media application

### [PAGE]

描述页面，例如：
- Smart itinerary homepage
- Product listing page
- Analytics overview page
- User profile page

### [LAYOUT]

布局描述，例如：
- mobile-first layout
- scrollable content
- bottom tabbar
- sidebar navigation
- grid layout

### [DESIGN_SYSTEM]

设计系统描述，例如：
- 8px spacing system
- soft shadow cards
- rounded corners
- blue accent color

### [COMPONENTS]

组件列表，例如：
- destination search bar
- travel recommendation cards
- weather widget
- itinerary timeline
- AI assistant floating button

### [STYLE]

风格描述，例如：
- Tencent mobile product design
- Apple iOS inspired UI
- realistic Chinese app interface
- production-ready layout

### [IMPLEMENTATION]

工程约束，例如：
- frontend-friendly
- component-based
- realistic app screenshot
- high fidelity
- suitable for frontend implementation

### [NEGATIVE]

负向约束，例如：
- not dribbble
- not futuristic
- not concept art
- not abstract
