# Speaker Style Distiller

为任意名人/演讲者蒸馏公开演讲/播客/访谈风格，输出 `style-card.md`。

## 何时触发

- 用户说"蒸馏马斯克的风格"
- 用户说"提取罗振宇的说话方式"
- 用户说"生成一张刘强东的风格卡"
- 用户说"我想让稿子像董宇辉那样讲"
- 用户提供一篇演讲稿，要求"分析这个人的风格"

## 输出

一个 `style-card-{name}.md` 文件，保存到 `speech-style-rewriter/style-cards/`。

## 工作流程

1. 检查 `speech-style-rewriter/style-cards/` 是否已有该人物风格卡。
2. 如果已有，询问是否重新蒸馏；如果用户要求更新，继续下一步。
3. 如果无，搜索该人物的公开演讲稿/发布会实录/播客访谈/高校演讲。
4. 清洗语料，保留口语特征、观众反应、口头禅；删除广告和旁观者评论。
5. 用分段标注 Prompt 分析每个段落的功能、情绪、修辞。
6. 提取 12 维风格特征：身份场景、开场钩子、口语化特征、节奏结构、重复金句、幽默方式、互动话术、叙事方式、数字数据、过渡句、结尾方式、改写指令。
7. 生成风格卡，包含 10 条可复用句式模板和安全边界。
8. 保存并返回摘要。

## 12 维风格卡结构

每张风格卡必须包含：

1. 参考来源
2. 身份与场景
3. 开场钩子
4. 口语化特征
5. 节奏与结构
6. 重复与金句
7. 幽默方式
8. 互动话术
9. 叙事方式
10. 数字与数据
11. 过渡句
12. 结尾方式
13. 改写指令模板
14. 可复用句式模板
15. 安全边界

## 语料来源优先级

1. 官方发布会文字实录
2. 年度演讲完整稿
3. 播客/访谈逐字稿
4. 高校演讲全文
5. 媒体整理全文稿
6. 社交媒体发言（仅作辅助）

## 分段标注 Prompt

```text
你是发布会演讲文本分析师。请分析下面这段演讲转录稿，并按功能标注每个段落。

输出 JSON 数组，每项包含：
- segment_type: opening_hook / background / pain_point / story / product_feature / data_proof / joke / self_mockery / audience_interaction / transition / closing / slogan
- emotional_tone: 真诚 / 讽刺 / 自嘲 / 激昂 / 克制 / 幽默 / 悲壮 / 务实
- rhetorical_devices: 反差 / 排比 / 设问 / 重复 / 数字 / 类比 / 夸张
- reusable_pattern: 可复用的话术结构
- representative_quote: 最能代表该段风格的一句话

文本:
<<<
{transcript_chunk}
>>>
```

## 风格卡生成 Prompt

```text
你是中文演讲风格研究员。请基于以下演讲片段，为该演讲者提取"可用于文本改写的风格卡"。

严格区分：
1. 可模仿的修辞与结构
2. 不应复制的具体事实、人物经历、商业承诺
3. 不应伪造的本人观点

按以下 15 个维度输出 Markdown 格式风格卡：
1. 参考来源
2. 身份与场景
3. 开场钩子
4. 口语化特征
5. 节奏与结构
6. 重复与金句
7. 幽默方式
8. 互动话术
9. 叙事方式
10. 数字与数据
11. 过渡句
12. 结尾方式
13. 改写指令模板（8-10 条）
14. 可复用句式模板（10 条）
15. 安全边界

语料:
<<<
{annotated_segments}
>>>
```

## 命名规范

- 中文名人：`style-card-luoyonghao.md`
- 英文名人：`style-card-steve-jobs.md`
- 保存路径：`speech-style-rewriter/style-cards/`

## 安全边界

- 只借鉴公开演讲中的结构、节奏、修辞和口语特征。
- 不声称文本由名人本人创作或发表。
- 不伪造名人本人观点、经历、商业承诺。
- 不新增未经用户提供的具体数据。
- 不直接复制大段原文。
- 避免生成损害在世名人声誉的内容。

## 配套 Skill

- `speech-style-rewriter`：使用本 Skill 生成的风格卡改写演讲稿。
