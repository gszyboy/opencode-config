# Speaker Style Distiller — 蒸馏方法论

> 本文件说明如何从公开演讲稿/播客/访谈中系统地蒸馏名人演讲风格。

---

## 一、为什么要蒸馏风格？

直接让 AI "模仿某某名人" 会有三个问题：

1. **风格不稳定**：每次输出差异大。
2. **容易越界**：可能伪造名人观点、经历、承诺。
3. **不可复用**：无法沉淀成可长期调用的资产。

蒸馏成 `style-card.md` 后：

- 风格结构化、可复用
- 可以和其他风格混合
- 可以版本化管理
- 可以避免冒充身份

---

## 二、蒸馏五步法

### Step 1: 收集语料

为指定名人收集 3-5 篇代表性演讲/播客/访谈：

| 场景 | 推荐来源 |
|------|---------|
| 产品发布会 | 官方发布会文字实录、媒体整理稿 |
| 年度演讲 | 公司官网、公众号全文 |
| 播客访谈 | 小宇宙、喜马拉雅、Apple Podcasts 逐字稿 |
| 高校演讲 | TED、 commencement speech、毕业典礼演讲 |
| 社交媒体 | 微博、Twitter/X（仅作辅助） |

收集原则：

- 优先完整稿，而非片段。
- 优先现场演讲稿，而非书面文章。
- 覆盖不同场景（发布会、访谈、演讲），避免风格单一。

---

### Step 2: 清洗语料

把原始文本转换成统一格式：

```json
{
  "speaker": "马斯克",
  "event": "Tesla Battery Day 2020",
  "year": 2020,
  "source_url": "...",
  "segment_id": "musk-battery-day-001",
  "segment_type": "opening / vision / data / product / closing",
  "text": "..."
}
```

清洗规则：

- 删除广告、导航、版权声明。
- 保留观众反应："掌声" "笑声" "欢呼"。
- 保留口头禅和重复词。
- 保留第一人称叙事。
- 按 300-800 字切块。

---

### Step 3: 分段标注

用以下标签标注每个段落：

- `opening_hook`：开场钩子
- `background`：背景铺垫
- `pain_point`：痛点/问题
- `story`：故事/案例
- `data_proof`：数据论证
- `product_feature`：产品/观点展开
- `joke`：幽默/段子
- `self_mockery`：自嘲
- `audience_interaction`：观众互动
- `transition`：过渡句
- `closing`：结尾
- `slogan`：金句/口号

同时标注：

- 情绪基调：真诚 / 讽刺 / 自嘲 / 激昂 / 克制 / 幽默 / 悲壮 / 务实
- 修辞手法：反差 / 排比 / 设问 / 重复 / 数字 / 类比 / 夸张
- 可复用话术结构
- 最具代表性的一句话

---

### Step 4: 提取 12 维风格特征

对每个维度，总结 3-5 条规则 + 1-2 个例子。

1. **身份与场景**：这个人是谁？在什么场合讲话？
2. **开场钩子**：通常怎么开场？
3. **口语化特征**：句子长短、语气词、口头禅、情绪词。
4. **节奏与结构**：整体叙事节奏是什么？
5. **重复与金句**：标志性表达、重复结构。
6. **幽默方式**：自嘲、反差、讽刺、冷幽默。
7. **互动话术**：怎么和观众互动？
8. **叙事方式**：个人故事、数据论证、宏大叙事？
9. **数字与数据**：怎么用数字？
10. **过渡句**：段落之间怎么衔接？
11. **结尾方式**：怎么收尾？
12. **改写指令模板**：总结为 AI 可直接执行的规则。

---

### Step 5: 生成并保存风格卡

输出为 Markdown 文件：

```
speech-style-rewriter/style-cards/style-card-{name}.md
```

命名规范：

- 中文名人：拼音小写 + 连字符
  - 例：`style-card-luoyonghao.md`
  - 例：`style-card-leijun.md`
- 英文名人：英文名小写 + 连字符
  - 例：`style-card-steve-jobs.md`
  - 例：`style-card-musk.md`

---

## 三、质量控制

生成风格卡后，做三个测试：

### 测试 1：已知答案测试

拿一段该名人的原文给 AI，让它用风格卡判断"这是否符合该风格"。

### 测试 2：改写测试

拿一段中性书面稿，用风格卡改写，检查：

- 是否像该名人的风格？
- 是否保留了原稿核心信息？
- 是否没有伪造事实？

### 测试 3：混合风格测试

尝试和另一种风格混合，检查是否可控。

---

## 四、常见错误

| 错误 | 原因 | 修正 |
|------|------|------|
| 风格卡太像人物传记 | 提取了过多事实，而非修辞 | 区分"可模仿结构"和"不可复制经历" |
| 风格卡只有口头禅 | 忽略了叙事结构和节奏 | 补充 12 维框架的每一维 |
| 风格卡过于抽象 | 缺少具体例子 | 每个维度加 1-2 个原文引用 |
| 风格卡无法改写 | 指令模板不够具体 | 把规则写成 AI 可执行的步骤 |
